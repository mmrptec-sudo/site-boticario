## Como publicar

1. Substitua o `index.html` do repositório por este arquivo.
2. Mantenha `imagem1.png` até `imagem7.png` **na mesma pasta de `index.html`**, respeitando maiúsculas/minúsculas.
3. Preserve as demais pastas `assets/`, `dados/` e `api/` do projeto e os arquivos adicionais.
4. Faça commit e aguarde o deploy do GitHub Pages / Vercel / hospedagem utilizada.

Não é necessário alterar o código para o celular: as mesmas imagens são usadas nos dois layouts, com recortes responsivos.

### Como verificar

Abra a aba Rede/Network do navegador e confirme que as imagens `imagem1.png` até `imagem7.png` carregam sem erro 404.

**Observação:** O arquivo ZIP deste projeto não inclui os sete PNGs recém-enviados ao GitHub; eles já estão no seu repositório. Imagens anteriores foram mantidas em `assets/` como fallback temporário. O ZIP inclui o restante do site e suas dependências.
